# 首次桌面 / NAS 验收

以下为待执行清单，不能将它当作已通过的测试报告。使用专门的测试共享和临时本地目录。

## 构建与启动

- [ ] Actions macOS ARM64 / Windows x64 的 Rust 测试、打包与冒烟检查通过；Cargo.lock 已纳入版本控制。
- [ ] Apple Silicon Mac 安装、启动、退出正常（当前不提供 Intel 版本）。
- [ ] macOS Keychain 初次保存、读取、重启重连、取消保存和移除凭据正常。
- [ ] Windows Credential Manager 同样验证；JSON 中没有密码。
- [ ] 访问 Downloads、桌面、文稿时的 macOS 权限提示和拒绝路径正确。

## 浏览与交互

- [ ] 两栏分别浏览 Local/Local、Local/SMB、SMB/Local、SMB/SMB。
- [ ] Samba、Windows SMB Server、实际 NAS 的 SMB2 和 SMB3；Domain、自定义端口、错误密码、离线服务器。
- [ ] 目录 10,000 项，滚动与选择流畅；加载不冻结另一栏。
- [ ] 双击目录，历史前进后退，地址输入，中文、空格、#、% 文件名。
- [ ] 单选、多选、Shift 范围、Cmd/Ctrl+A；排序后操作仍对应选中名称。
- [ ] 快速切换多个目录，迟到的旧请求不会覆盖新目录。
- [ ] 右键操作、所有文档列出的快捷键，窗口缩到最小尺寸仍可用。

## 传输与故障

- [ ] 空文件、小文件、超过 4 GiB 的文件；对比 SHA-256 一致。
- [ ] 嵌套目录和空目录；跨栏与子文件夹拖放。
- [ ] 各种 Local/SMB 方向的复制、移动；SMB/SMB 使用两台服务器。
- [ ] 同名文件：替换、跳过、取消；已有目标在取消或失败后仍可恢复。
- [ ] 同名目录合并，文件与目录同名安全失败或跳过。
- [ ] 传输中断网、服务器重启、权限拒绝、目标磁盘满；显示错误且可重试。
- [ ] 排队时取消、传输时取消、冲突等待时取消；完成清理后可重试。
- [ ] 传输期间改变源或目标，能检查常见大小 / 修改时间变化并停止。
- [ ] 向自身 / 子目录复制被拒绝；不跟随本地符号链接递归复制或删除。
- [ ] 移动时新增目录内容，不误删新增文件；部分失败的源文件保留。
- [ ] 正常取消清理临时文件；强制退出后按 README 检查 part / backup。
- [ ] 浏览、拖放、冲突确认期间取消关闭窗口；有任务时关闭会提醒。

## 测量

记录 Mac 型号、系统版本、NAS / SMB 协商版本、网络条件、Release 构建版本。

- [ ] 启动时间；空闲 / 浏览 10,000 项 / 传输大文件时的 RSS 与 CPU。
- [ ] 连续传输 30 分钟，内存不随文件长度增长；吞吐无明显持续下降。
- [ ] 反复进入目录与重试连接后，服务器没有持续累积文件句柄或连接。

当前前端约 48.5 KB JavaScript、10 KB CSS（构建原始体积），不能由此推断整个进程内存或安装包大小。
